# 🚀 Apar's School Management System

A modern web application built with Next.js, Tailwind CSS, and Lucide React.

## 🛠️ Getting Started
Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### 1. Prerequisites
Make sure you have Node.js (Version 18.x or higher) installed on your system.
- Download Node.js
- Check version: `node -v`

### 2. Installation
First, clone the repository:
```bash
git clone https://github.com
cd your-repo-name
```

Install the dependencies using npm, yarn, or pnpm:
```bash
npm install
yarn install
pnpm install
```


### 3. Environment Setup
Create a `.env.local` file in the root directory and add your environment variables (if any):
```env
NEXT_PUBLIC_API_URL=your_api_url_here
# Add other keys as needed
```

### 4. Running the Development Server
Start the local development server:
```bash
npm run dev
yarn dev
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🏗️ Building for Production
To create an optimized production build:
```bash

npm run build
npm run start 

yarn build
yarn start 

pnpm run build 
pnpm run start 

```

## 📁 Project Structure
- `src/app` - Next.js App Router (Pages, Layouts, Components)
- `/public` - Static assets (images, icons, etc.)
- `src/app/components` - Reusable UI components
- `src/app/data` - Mock data or constant files

## 🌐 Deployment

The easiest way to deploy your Next.js app is to use the Vercel Platform.

- Push your code to GitHub.

- Import your project into Vercel.

- Vercel will automatically detect Next.js and deploy.
